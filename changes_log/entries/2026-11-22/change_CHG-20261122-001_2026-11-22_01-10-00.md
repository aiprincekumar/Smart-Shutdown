## 📋 1. Purpose & Architectural Rationale

Modernize Windows Startup launch mechanism so that on Windows boot:
- The unified Antigravity Auto Shutdown Sentinel desktop GUI launches automatically instead of legacy headless scripts.
- It starts silently and unobtrusively in compact HWND_TOPMOST Mini HUD mode (`--mini-hud`).
- The main Sentinel GUI window remains withdrawn (`withdraw()`) until the user clicks 'EXPAND TO FULL GUI' on the mini overlay.
- Low-level physical hardware keyboard/mouse activity hooks (`core/input_hook.py`) track user presence in real-time, instantly resetting idle timers on human touch.
- Windows startup shortcut management (`core/startup.py` and `scripts/07_toggle_windows_boot_startup.py`) targets `antigravity_auto_shutdown.py` with `--mini-hud` argument.

- **Change Type:** `feat(startup)`
- **Execution Protocol:** 4-Level Command Hierarchy & Parallel Specialist Decision Gate (Token `AUTH-MGR-20261121-STARTUP-ALLINONE-001`).
- **System Impact:** Complete all-in-one GUI workflow seamlessly integrated with Windows boot startup and real-time physical user interactivity.
